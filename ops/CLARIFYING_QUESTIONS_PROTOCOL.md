# CLARIFYING_QUESTIONS_PROTOCOL.md

22:00 로그 이후, 05:00 브리핑 정확도를 높이기 위한 보완 질문 규칙.

## 목적
- 중복 입력 없이 plna 원본 데이터의 빈칸을 보완
- 질문 과다를 방지하고 핵심만 묻기

## 질문 발송 시점
- 기본: 22:05
- 로그가 충분하면 질문 생략 가능

## 질문 개수 제한
- 최대 5개
- 우선순위 높은 질문부터 순서대로

## 질문 우선순위
1. 내일 Top3의 마감/시간 누락
2. 리스크가 모호하거나 대응이 없는 경우
3. 미완료 항목의 원인 불명확
4. 목표(주/월/분기) 연결이 빠진 경우
5. 실행 시작점(첫 30분 행동) 불명확

## 질문 템플릿

1) 내일 최우선 1번의 정확한 마감 시간은?
2) 오늘 가장 큰 리스크 1개와 대응 1개를 적어줘.
3) 미완료 항목 중 내일로 넘길 1개만 확정해줘.
4) 내일 Top3 중 연구대회와 직접 연결되는 항목은?
5) 내일 첫 30분에 바로 시작할 행동 1개는?

## 응답 반영 규칙
- 답변은 todos/journal에 구조화 반영
- 모호한 답변은 Prep로 표기하고 05:00 브리핑에 경고 포함
- 미응답이면 기존 plna 데이터로 최소 브리핑 생성
