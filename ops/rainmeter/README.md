# PLNA 바탕화면 위젯 (Windows / Rainmeter)

윈도우 바탕화면에 오늘의 습관 진행률·남은 할 일·이번 주 목표를 띄운다.

## 왜 Rainmeter가 필요한가

PLNA는 앱이 아니라 웹사이트다. 윈도우 바탕화면에 그림을 그릴 수 있는 것은 **설치된 프로그램**뿐이라,
웹사이트가 직접 바탕화면에 붙을 수는 없다. Rainmeter는 그 역할을 대신해 주는 무료 프로그램이고,
여기 있는 `PLNA.ini`가 "PLNA 위젯 이미지를 15분마다 받아서 바탕화면에 그려라"는 설정이다.

서버 쪽(`/api/widget/image`)은 이미 동작하므로, 여기서 하는 일은 그 그림을 바탕화면에 거는 것뿐이다.

## 파일을 내려받을 수 없을 때

`PLNA.ini`는 그냥 텍스트 파일이라 **다운로드 없이 직접 만들 수 있다.**

1. 메모장을 연다.
2. `PLNA.ini`의 내용을 전부 복사해 붙여넣는다. (일부러 영문만 써서 인코딩 문제가 없다)
3. `파일 → 다른 이름으로 저장`
   - 파일 형식: **모든 파일 (*.*)**  ← 이걸 안 바꾸면 `PLNA.ini.txt`가 된다
   - 인코딩: **ANSI**
   - 파일 이름: `PLNA.ini`
   - 위치: `문서\Rainmeter\Skins\PLNA\`

Rainmeter 설치 파일조차 받을 수 없다면 아래 **무설치 대안**을 쓴다.

## 설치

1. **Rainmeter 설치** — <https://www.rainmeter.net> 에서 내려받아 설치한다. 무료다.
   설치 중 옵션은 기본값 그대로 두면 된다.

2. **스킨 폴더에 복사** — 이 저장소의 `ops/rainmeter/PLNA` 폴더를 통째로 아래 위치에 복사한다.

   ```
   문서\Rainmeter\Skins\
   ```

   복사 후 경로가 이렇게 되어야 한다.

   ```
   문서\Rainmeter\Skins\PLNA\PLNA.ini
   ```

3. **토큰 입력** — `PLNA.ini`를 메모장으로 열고 `Token=` 줄을 본인 값으로 바꾼다.

   ```ini
   Token=YOUR_WIDGET_TOKEN        ← 이 줄을
   Token=a1b2c3d4e5f6...          ← 실제 값으로 (꺾쇠 < > 는 넣지 않는다)
   ```

   Vercel 환경변수 `PLNA_WIDGET_TOKEN`에 넣은 값과 **똑같아야** 한다. 저장하고 닫는다.

4. **불러오기** — 작업표시줄 오른쪽 아래 Rainmeter 아이콘을 우클릭 →
   **새로 고침 전체(Refresh all)** → 다시 우클릭 → **스킨(Skins)** → **PLNA** → **PLNA.ini** 클릭.

   바탕화면에 위젯이 나타난다.

5. **위치 잡기** — 위젯을 마우스로 끌어 원하는 자리에 놓는다.
   자리를 잡았으면 Rainmeter 관리 창에서 **위치 고정(Draggable 해제)** 을 해두면 실수로 안 움직인다.

## 설정 바꾸기

`PLNA.ini`의 `[Variables]` 부분만 고치면 된다. 고친 뒤에는 위젯을 우클릭 → **새로 고침**.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| `Token` | — | Vercel의 `PLNA_WIDGET_TOKEN` 값 |
| `Theme` | `light` | 배경화면이 어두우면 `dark` |
| `DisplayWidth` / `DisplayHeight` | `500` / `250` | 바탕화면에 보일 크기 |
| `RenderWidth` / `RenderHeight` | `1000` / `500` | 내려받는 크기. **보이는 크기의 2배**로 두면 글자가 또렷하다 |
| `RefreshSeconds` | `900` | 새로고침 주기(초) |

`RefreshSeconds`를 900초(15분)보다 짧게 잡아도 의미가 없다. 서버가 300초 동안 같은 응답을 돌려주고,
더 줄이면 Firestore 읽기만 늘어난다.

크기를 바꿀 때는 가로:세로 **2:1** 비율을 유지해야 여백 없이 맞는다.

## 동작

- **클릭** — PLNA가 브라우저에서 열린다.
- **우클릭 → 지금 새로고침** — 15분을 기다리지 않고 즉시 다시 받아온다.
- 배경이 투명한 PNG라 배경화면 위에 카드처럼 얹힌다.

## 문제가 생기면

| 증상 | 원인 | 해결 |
|------|------|------|
| 빨간 글씨 "Token 값이 맞는지 확인하세요" | 토큰 불일치 | `PLNA.ini`의 `Token`과 Vercel 값이 같은지 확인. 꺾쇠 `< >`가 섞여 있지 않은지 확인 |
| 빨간 글씨 "인터넷 연결을 확인하세요" | 네트워크 문제 | 브라우저에서 위젯 주소가 열리는지 먼저 확인 |
| 아무것도 안 보임 | 스킨 미로드 | Rainmeter 우클릭 → 새로 고침 전체 후 다시 불러오기 |
| 글자가 흐릿함 | 렌더 크기 부족 | `RenderWidth`/`RenderHeight`를 보이는 크기의 2배로 |
| 내용이 안 바뀜 | 캐시 | 우클릭 → 지금 새로고침. 그래도 그대로면 서버 캐시(최대 300초) 대기 |

먼저 브라우저에서 아래 주소가 열리는지 확인하면 서버 문제인지 Rainmeter 문제인지 구분된다.

```
https://plna.vercel.app/api/widget/image?token=<본인 토큰>&w=1000&h=500
```

## 무설치 대안 (아무것도 안 받아질 때)

앱에 `/widget` 페이지가 있다. 위젯 이미지를 5분마다 자동으로 다시 불러오는 페이지라,
크롬 창 하나를 위젯처럼 띄워 두면 된다. **설치도 다운로드도 필요 없다.**

```
https://plna.vercel.app/widget?token=<본인 토큰>
```

1. 크롬에서 위 주소를 연다.
2. 오른쪽 위 `⋮` → `저장 및 공유` → `바로가기 만들기...`
3. **`창으로 열기`를 체크**하고 만들기.
4. 바탕화면에 생긴 아이콘을 더블클릭하면 주소창 없는 창으로 열린다.
5. 창을 위젯 크기로 줄여 화면 구석에 둔다.

옵션은 주소 뒤에 붙인다.

| 옵션 | 예 | 설명 |
|------|-----|------|
| `theme` | `&theme=dark` | 어두운 테마 |
| `refresh` | `&refresh=600` | 자동 새로고침 주기(초). 최소 30, 기본 300 |
| `w` / `h` | `&w=1000&h=500` | 받아올 이미지 크기 |

Rainmeter와 달리 **항상 위에 고정되지는 않아** 다른 창에 가려질 수 있다.
그 점만 빼면 결과는 같다.
