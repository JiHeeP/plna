# 앱 접근 게이트 (매직 링크)

PLNA 는 개인 기록이고 쓰기 API 에 인증이 없었다. 주소만 알면 누구나 습관 체크와
할 일을 바꿀 수 있었다. 그래서 앱 전체를 게이트 뒤에 두었다.

로그인 화면도 비밀번호 입력도 없다. **키가 들어간 주소를 기기에서 한 번 열면
그 기기가 등록되고, 그 뒤로는 평소처럼 쓴다.**

## 1. 서버 설정

1. 키를 만든다.

   ```bash
   openssl rand -hex 24
   ```

2. Vercel 환경 변수에 넣는다(로컬은 `.env.local`).

   ```
   PLNA_ACCESS_KEY=<위에서 만든 값>
   ```

3. 재배포한다.

> **키를 넣기 전에 배포하면 앱이 503 으로 닫힌다.** 일부러 그렇게 했다. 깜빡 잊은
> 배포가 앱을 통째로 여는 쪽이 더 위험하기 때문이다. 503 화면에 무엇을 해야 하는지 적혀 있다.

## 2. 기기 등록 (기기마다 한 번)

주소 끝에 키를 붙여 연다.

```
https://plna.vercel.app/?key=<PLNA_ACCESS_KEY>
```

열리는 순간 서버가 1년짜리 쿠키를 심고, 주소에서 `key` 를 지운 채 같은 페이지로 보낸다.
그 뒤로는 `https://plna.vercel.app/` 만으로 들어간다.

| 기기 | 방법 |
|------|------|
| 폰·PC 브라우저 | 위 주소를 한 번 연다. 홈 화면 바로가기는 그 뒤에 만든다 |
| 데스크톱 위젯(Tauri) | 첫 실행만 `plna-widget.exe --key=<키>` (또는 `PLNA_ACCESS_KEY` 환경 변수) |
| 안드로이드 홈 화면 위젯 | 등록이 필요 없다 — 위젯 토큰으로 따로 인증한다 |

## 3. 게이트를 지나치는 것

- `/api/widget/*` — 홈 화면 위젯은 쿠키를 가질 수 없어서 위젯 토큰으로 스스로 인증한다
  (`PLNA_WIDGET_TOKEN` / `PLNA_WIDGET_WRITE_TOKEN`, `docs/android-widget.md` 참고)
- `/_next/*`, `/icons/*`, `manifest.json` 등 정적 자산

## 4. 되돌리기·교체

- **기기 하나를 빼고 싶다** → 그 기기 브라우저에서 사이트 데이터를 지운다.
- **전부 무효로 만들고 싶다** → `PLNA_ACCESS_KEY` 를 새 값으로 바꾸고 재배포한다.
  쿠키 값은 키에서 파생되므로 기존 쿠키가 한 번에 무효가 된다. 기기마다 새 링크를 다시 연다.

## 5. 어떻게 동작하나

- 쿠키에는 키가 아니라 키로 만든 HMAC-SHA256 값이 들어간다. 쿠키가 새도 키는 안 샌다.
- 쿠키는 `httpOnly`·`sameSite=lax`·HTTPS 에서 `secure`. 자바스크립트로 읽히지 않는다.
- 판단 로직은 `lib/access-gate.ts`, 적용은 `proxy.ts`(Next 16 규약) 에 있다.
  테스트는 `tests/access-gate.test.ts`.

## 6. 한계

- 키를 아는 사람은 누구나 기기를 등록할 수 있다. 링크를 공유하지 않는 것이 전부다.
- 사용자 구분이 없다. 이 앱은 한 사람이 쓰는 기록이라 그렇게 두었다.
